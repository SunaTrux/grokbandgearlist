# ギア帳 / GEAR CHO

バンドマン向けの持ち物リストアプリです。  
スタジオ・ライブ・レコーディングを日付・会場ごとに保存し、パート（共通 / Gt / Ba / Dr / Vo / Key / カスタム）ごとにチェックできます。

データはこの端末のブラウザに保存されます。サーバには送りません。

## すぐ使う

`index.html` をブラウザで開くだけです。  
iPhone なら Safari → 共有 → **ホーム画面に追加** でアプリのように使えます。

## できること

- 日付ごとの予定（会場名・タイトルつき）
- 新しい予定に定番テンプレ、または前回の同じ種類のリストをコピー
- パート別リスト、必須マーク、数量、メモ
- 定番テンプレートの読み込み
- チェックの一括解除
- 共有テキスト（LINE向け）と共有リンク
- JSONバックアップの書き出し / 読み込み
- カスタムパート追加（Sax / DJ / PA など）

## 公開の仕方

### リストを公開する

アプリ内の「共有 / 公開」から

1. テキストをコピーして LINE / Discord / メモ帳へ
2. リンクをコピーして相手に送る（相手側で「取り込む」）

### アプリ自体をサイトとして公開する

このフォルダ一式を置けば公開できます。

- [GitHub Pages](https://pages.github.com/)
- [Netlify Drop](https://app.netlify.com/drop)（フォルダをドラッグするだけ）
- [Cloudflare Pages](https://pages.cloudflare.com/)

App Store / Google Play への申請は、デベロッパー登録と審査が別途必要です。まずは Web 公開が最短です。
